# Home Credit LAP Qualification Voice Agent

## Overview
An AI voice agent built in Retell AI for the Home Credit Loan Against Property (LAP) qualification assignment. It informs existing customers about a pre-approved LAP offer of up to ₹75 lakh and conducts a preliminary eligibility check.

## Features
- Verifies the customer’s identity and availability before proceeding.
- Explains the LAP offer and collects eligibility details.
- Checks property type, ownership, original documents, requested amount, occupation, income mode, property value, and loan tenure.
- Ends the qualification flow when an eligibility condition is not met.
- Handles loan-transfer or EMI-reduction requests by directing the customer to a specialist.
- Provides a preliminary result and arranges a follow-up from a senior loan expert.
- Uses a conversational, professional tone.

## Technology
- Retell AI
- Single-prompt voice agent
- English (India)

## Testing
The agent was tested using Retell’s web-call simulator with a sample eligible customer. The test call recording and transcript were saved for review.
